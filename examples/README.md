# ADE Examples

The examples directory contains lightweight workflows for running ADE locally.
Examples use synthetic data generated by the repository and do not download
external datasets.

- [Demo workflow](demo_workflow.md): generate demo images, run the current visual-data pipeline, validate reports, export HTML, record feedback, run a local benchmark, and execute the full local verification script.
- [Modality examples](modalities/README.md): current visual workflow, CSV adapter foundations, and planned adapter targets.

Generated example outputs are written under `data/` and are ignored by the
repository. All discoveries are candidate findings that require human review.
