# ADE v0.1.0 Private Alpha Release Notes

Release name: ADE v0.1.0 Private Alpha

Release date: `<DATE>`

## Scope

This private-alpha release packages ADE as a local, adapter-based autonomous
discovery platform for recruiter review, technical interviews, and early
private-alpha feedback. It is a local workflow release, not a production SaaS
or hosted deployment.

The visual/image-folder workflow is the most mature path. CSV tabular and CSV
time-series workflows are lightweight foundations with local CLI reports.

## Implemented Capabilities

- Visual/image-folder local discovery workflow.
- CSV tabular local workflow for lightweight row-level candidate anomalies.
- CSV time-series local workflow for timestamped candidate patterns.
- Candidate anomaly and candidate concept reporting.
- Markdown, JSON, and static HTML report outputs.
- Report validation and stable review target IDs.
- Local run history.
- Benchmark script for local repeatability checks.
- Local dashboard export from existing generated artifacts.
- Local human-review feedback JSONL.
- Review-informed memory signals for future ranking support.
- Local verification script and test coverage.

## Demo Workflows

Recommended quick demo:

```powershell
python scripts/create_demo_data.py
python -m ade.cli --input data/raw/demo_images --output data/reports/demo_report.md
python -m ade.cli --validate-report data/reports/demo_report.json
python -m ade.cli --export-html-report data/reports/demo_report.json --output data/reports/demo_report.html
python scripts/run_benchmark.py --input data/raw/demo_images --config configs/default.yaml --output data/benchmarks/demo_benchmark.json
python -m ade.cli --export-local-dashboard --output data/dashboard
```

## Known Limitations

- Candidate findings require human review.
- ADE does not claim automated truth or production decision authority.
- The visual workflow is the most mature path.
- CSV tabular and CSV time-series workflows are lightweight local foundations.
- Audio, live satellite feeds, sensor streams, production streaming, hosted
  dashboards, auth/users, database services, billing, and enterprise deployment
  are not implemented.
- Local feedback is not a production audit trail.
- Current scoring and representation are deterministic baselines, not deep
  model claims.

## Planned Next Milestones

- Harden adapter contracts and evidence rendering.
- Expand review workflows around local feedback JSONL.
- Improve concept memory and review-informed ranking support.
- Evaluate optional stronger representation backends behind existing
  interfaces.
- Design hosted review architecture only after the local private-alpha workflow
  is stable.

## What Not To Claim

- Do not claim production readiness.
- Do not claim production SaaS, cloud deployment, auth, database-backed review,
  billing, or enterprise deployment.
- Do not claim audio, live satellite feeds, sensor streams, or production
  streaming are implemented.
- Do not claim supervised learning or automated truth from feedback.
- Do not present candidate anomalies or candidate concepts as verified facts.

## Upgrade and Compatibility Notes

- Report JSON remains the primary structured artifact for local review tools.
- Stable `anomaly_id` and `concept_id` values are the feedback target contract.
- Generated artifacts remain local and ignored by Git.
- The private-alpha scope may change before any public or production release.
